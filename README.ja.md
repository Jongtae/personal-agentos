# AgentOS

[English](README.md) | [한국어](README.ko.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

AgentOS はローカルファーストのパーソナルエージェント・ランタイムです。所有者のメモリ、コンテキスト、ツール権限、作業キュー、承認、証跡を Mac 上のユーザースコープで分離されたランタイムに保持し、Codex や Claude Code などの接続済み AI 実行エンジンを使って作業を完了します。

日常的な操作画面は個人用 Telegram ボットです。AgentOS は単なるメッセージ中継ではありません。アシスタントを選択し、ツールとデータの境界を適用し、作業状態を永続化し、その結果と証跡を記録します。

## 現在のベースライン

バージョン 1.0.3 は、保守が継続されるセルフホスト型 API モデルのプレビューです。Hub v2 は現在の製品ロードマップであり、サブスクリプション接続された実行エンジン、所有者が BotFather で作成してローカルランタイムに非公開でペアリングする Telegram ボット、オプトインのローカルコンテキスト受信箱を含みます。ボットトークンは一度だけ入力され、ローカルの非公開接続ストアにのみ保持されます。設定、イベント、エクスポート、ログ、受け入れレポートには含まれません。[Hub v2 の製品基盤](docs/agentos-hub-v2.ko.md)を参照してください。

所有者の状態は `scripts/agentos-backup.py DATA ARCHIVE` と `scripts/agentos-restore.py ARCHIVE EMPTY_DATA` により、ローカルランタイム間で移動できます。アーカイブは完全性チェックを受け、メモリ、作業の証跡、レビュー済みのアシスタント宣言を含みます。認証情報、セッション、ローカルフォルダの許可、エンジン／モデルの選択、Telegram のペアリングは含みません。移行先ランタイムは明示的に所有権を取得し、再接続してください。

## 開発用インストール

```sh
brew install jongtae/agentos/agentos
agentos start
```

v2 のコンシューマー向けインストーラーが完成するまで、Homebrew の経路は開発者とセルフホスト利用者向けに維持されます。

## ガバナンス

アクティブな Hub v2 マイルストーンにはすべて、GitHub issue、ブランチ、PR、自動検証、名前付きの実運用受け入れ証跡があります。実装前に [AGENTS.md](AGENTS.md)、[PRD.md](PRD.md)、[TASKS.md](TASKS.md)、[ロードマップ](docs/roadmap.md)を読んでください。
