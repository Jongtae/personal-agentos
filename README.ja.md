# AgentOS

[English](README.md) | [한국어](README.ko.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

AgentOS は、所有者が管理するファイルとフォルダを中心にしたローカルファーストのパーソナルエージェントです。ソース資料を保持し、会話と作業で利用し、再利用可能な結果を通常のファイルとして保存します。Mac 上のユーザースコープで分離されたランタイムには、ポリシー、作業キュー、承認、証跡、復旧状態を保持します。

体験は個人用 Telegram ボットを含む会話と作業であり、既知の資料を何度も選ばせるファイルマネージャーではありません。AgentOS は単なるメッセージ中継ではありません。アシスタントを選択し、ツールとデータの境界を適用し、作業状態と結果・証跡を記録します。

## 現在の方向

ファイルとフォルダが資料の基盤で、会話と作業が体験です。接続した参照フォルダは既定で読み取り専用とし、AgentOS は所有者が許可した管理ワークスペース内でのみ新しい資料と結果を書き込みます。原本、抽出テキスト・要約、下書き、確定記録は区別し、再生成可能な検索インデックスは永続的な作業・承認・証跡・復旧・認証状態から分離します。外部 AI、メッセンジャー、他のエージェントへの送信は別のポリシー／承認境界です。

バージョン 1.0.3 と Hub v2/Drive の配信履歴は歴史的な証拠として保持し、現在の製品選択子にはしません。現在アクティブなプログラムは [#314 ファイルとフォルダの個人ワークスペース](https://github.com/Jongtae/personal-agentos/issues/314) であり、最初の実装はまだ開始していません。Drive などのサービスコネクタは任意のインポート／サービス操作であり、保存基盤ではありません。AgentOS はクラウド同期エンジンや中央認証サーバーを追加しません。

所有者の状態は `scripts/agentos-backup.py DATA ARCHIVE` と `scripts/agentos-restore.py ARCHIVE EMPTY_DATA` により、ローカルランタイム間で移動できます。アーカイブは完全性チェックを受け、メモリ、作業の証跡、レビュー済みのアシスタント宣言を含みます。認証情報、セッション、ローカルフォルダの許可、エンジン／モデルの選択、Telegram のペアリングは含みません。移行先ランタイムは明示的に所有権を取得し、再接続してください。

## 開発用インストール

```sh
brew install jongtae/agentos/agentos
agentos start
```

v2 のコンシューマー向けインストーラーが完成するまで、Homebrew の経路は開発者とセルフホスト利用者向けに維持されます。

アクティブな Hub v2 マイルストーンにはすべて、GitHub issue、ブランチ、PR、自動検証、名前付きの実運用受け入れ証跡があります。実装前に [AGENTS.md](AGENTS.md)、[PRD.md](PRD.md)、[TASKS.md](TASKS.md)、[ロードマップ](docs/roadmap.md)を読んでください。
